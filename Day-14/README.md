# Day 14: Implement Prime Number Analysis

## 📌 Description
This project implements a Java program to analyze prime numbers. It checks whether a number is prime, generates prime numbers up to a specified limit, and identifies prime numbers within a given range.

## 🎯 Objective
- Practice loops and conditional statements.
- Understand mathematical logic.
- Improve algorithmic thinking.
- Learn to use methods in Java.

## 🛠️ Tools Used
- Java
- JDK
- Java IDE or text editor

## ✨ Features
- **Prime Checker:** Checks whether a number is prime.
- **Prime Number Generator:** Generates prime numbers up to a specified limit.
- **Range-Based Prime Analysis:** Finds prime numbers within a given range.
- **Input Validation:** Handles numbers less than 2 and invalid ranges.
- **Optimized Checking:** Tests divisors up to the square root of a number.

## 💻 How to Run

### 1. Save the Java File

Save the program as `PrimeNumberAnalysis.java`.

### 2. Compile the Program

```bash
javac PrimeNumberAnalysis.java
```

### 3. Run the Program

```bash
java PrimeNumberAnalysis
```

## 📚 What Is a Prime Number?

A prime number is a natural number greater than 1 that has exactly two factors: 1 and itself.

**Examples:** `2, 3, 5, 7, 11, 13, 17, 19`

**Note:** The number `1` is not a prime number.
