# ATM Simulation in Java

## 📌 Description

This project is a **console-based ATM Simulation** developed using Java. It allows users to access their account using a PIN and perform basic ATM operations such as checking balance, depositing money, and withdrawing money.

## 🎯 Objective

The main objective of this project is to practice:

- Conditional statements
- Loops
- Methods
- Switch-case
- User input using `Scanner`
- PIN verification
- Account balance management
- Error handling

## 🛠️ Technology Used

- **Programming Language:** Java
- **Input:** Scanner
- **Application Type:** Console-based

## ✨ Features

- 🔐 PIN authentication
- 🔢 Maximum 3 incorrect PIN attempts
- 💰 Balance checking
- 💵 Deposit money
- 💸 Withdraw money
- 🚫 Prevent withdrawal greater than balance
- ⚠️ Handle invalid transaction amounts
- 📋 Menu-driven ATM interface
- 🚪 Exit option
