
# Student Grade Management System

## 📌 About the Project

The Student Grade Management System is a Java-based console application designed to manage student records, subjects, marks, grades, and academic performance.

This application allows users to add, display, search, update, and delete student records. It also calculates grades, average marks, and generates academic performance summaries.

## 🎯 Objectives

- Understand Java fundamentals.
- Learn classes and objects.
- Implement methods and constructors.
- Work with ArrayList collections.
- Apply conditional statements and loops.
- Perform CRUD operations.
- Calculate student grades and academic performance.

## ▶️ How to Run the Project

### Step 1: Install Java

Install JDK on your computer.

### Step 2: Create a Java File

Save the source code as:

`StudentGradeManagementSystem.java`

### Step 3: Compile the Program

```bash
javac StudentGradeManagementSystem.java
```

### Step 4: Run the Program

```bash
java StudentGradeManagementSystem
```
