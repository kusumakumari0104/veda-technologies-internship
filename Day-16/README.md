# 📚 Library Management System in Java

## 📌 Description
Create a console-based library management system that manages books, members, issuing books, returning books, and overdue fine tracking.

## 🎯 Objective
Apply Object-Oriented Programming (OOP) concepts to develop a realistic library management application using Java.

## 🛠️ Tools and Technologies
- Java
- ArrayList Collections
- Scanner Class
- Java Date and Time API

## ✨ Features
- Add and view books
- Register and view members
- Issue books to members
- Return issued books
- Calculate overdue days and fines
- View currently issued books
- Menu-driven console interface

## ▶️ How to Run

**Step 1: Compile the Java program**

```bash
javac LibraryManagementSystem.java
```

**Step 2: Run the program**

```bash
java LibraryManagementSystem
```
