# Multiplication Table Generator

## Description

The **Multiplication Table Generator** is a Java program that generates multiplication tables for a user-provided number. It can also generate multiplication tables for a range of numbers.

## Objective

- Practice `for` loops.
- Understand nested loops.
- Use methods in Java.
- Generate formatted console output.
- Handle user input using `Scanner`.

## Features

- Generate a multiplication table for a single number.
- Generate tables for a range of numbers.
- Uses a separate method for table generation.
- Provides formatted and easy-to-read output.
- Handles invalid menu choices.

## Technologies Used

- Java
- Scanner
- For Loop
- Nested Loops
- Methods
- Switch Statement

```text
MultiplicationTableGenerator

├── main()
