# Palindrome Checker
## 📌 Description
This Java program checks whether a given **string** and **number** are palindromes.

A palindrome is a word, string, or number that reads the same **forward and backward**.

### Examples

- `Madam` → Palindrome
- `121` → Palindrome
- `Hello` → Not a palindrome
- `123` → Not a palindrome

## 🎯 Objective

- Practice Java strings and loops.
- Understand character manipulation.
- Learn how to check a palindrome.
- Perform **case-insensitive** string checking.
- Practice methods and conditions in Java.
