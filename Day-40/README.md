# Expense Management System

## About
The Expense Management System is a Java-based application designed to record and manage daily expenses. It allows users to add, edit, delete, and search transactions, categorize expenses, set monthly budgets, and generate financial summary reports.

## Objectives
- Record daily expenses.
- Categorize transactions.
- Set monthly budgets.
- Generate financial summaries.
- Add, edit, delete, and search transactions.
- Store expense details using file handling.
