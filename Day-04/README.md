# Student Management System Using Arrays

## Description

A simple **console-based Student Management System** developed in Java using **arrays**. The program allows users to add, search, update, and display student records.

## Objective

The main objective of this project is to practice:

- Arrays
- Methods
- Loops
- Conditional statements
- Switch-case
- Scanner input
- Basic CRUD operations

## Features

- **Add Student** – Add a new student record.
- **Search Student** – Search for a student using Student ID.
- **Update Student** – Update existing student information.
- **Display Students** – Display all student records.
- **Exit** – Exit the application.
- Prevents duplicate Student IDs.
- Handles invalid Student IDs.

## Technologies Used

- **Programming Language:** Java
- **Concept:** Arrays
- **Input:** Scanner
- **Application Type:** Console-based

## Student Information

Each student record contains:

| Field | Description |
|---|---|
| Student ID | Unique ID of the student |
| Student Name | Name of the student |
| Student Age | Age of the student |
| Student Course | Course taken by the student |

## CRUD Operations

CRUD stands for:

- **C - Create:** Add a student
- **R - Read:** Search and display student records
- **U - Update:** Modify student information
- **D - Delete:** Not implemented in this version
