# Veda Technology Business & Service Management System

## 📌 Project Description

The Veda Technology Business & Service Management System is a Java-based application designed to manage the operations of a technology and digital-services organization.

The system manages service categories, technology training programs, customer inquiries, internship programs, and service requests using sample synthetic data.

## 🎯 Objectives

- Apply Java Object-Oriented Programming concepts.
- Understand inheritance and encapsulation.
- Implement collections to manage application data.
- Practice exception handling.
- Develop a menu-driven application.
- Implement searching and reporting functionality.

## ⚙️ How to Run the Project

### Step 1: Install Java

Install JDK on your computer.

### Step 2: Compile the Program

    javac VedaTechnologySystem.java

### Step 3: Run the Program

    java VedaTechnologySystem
