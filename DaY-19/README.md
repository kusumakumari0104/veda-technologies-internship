# Build a Unique Email Registry Using HashSet

## 📌 Description
Create a Java application that stores unique email addresses and prevents duplicate registrations using the `HashSet` collection.

## 🎯 Objective
- Understand sets and uniqueness constraints.
- Learn how to use Java `HashSet`.
- Prevent duplicate email registrations.
- Perform email registration, removal, and listing.

## 🛠️ Tools Used
- Java
- HashSet
- Scanner
- VS Code / Eclipse / IntelliJ IDEA

## ✨ Features
- Register a new email address.
- Detect and prevent duplicate emails.
- Validate email address format.
- Remove registered email addresses.
- Display all registered email addresses.
- Convert email addresses to lowercase.
- Exit the application.
