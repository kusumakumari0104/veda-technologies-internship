# Command-Line Calculator

A simple **Java console application** that performs basic arithmetic operations based on user input.

## Description

This project is a command-line calculator developed using Java. It allows the user to enter two numbers and select an arithmetic operation.

The calculator supports:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)

It also handles **invalid input** and **division/modulus by zero**.

## Objective

The main objectives of this project are to learn and practice:

- Java syntax
- Variables and data types
- Operators
- `Scanner` for user input
- `switch` statements
- Methods
- Exception handling
- Input validation
- Basic program structure

## Technologies Used

- **Programming Language:** Java
- **JDK:** Java Development Kit
- **IDE:** VS Code / IntelliJ IDEA / Eclipse

## Features

1. Addition of two numbers
2. Subtraction of two numbers
3. Multiplication of two numbers
4. Division of two numbers
5. Modulus of two numbers
6. Invalid operation handling
7. Invalid number input handling
8. Division by zero validation
9. Modulus by zero validation
10. Separate methods for each operation
